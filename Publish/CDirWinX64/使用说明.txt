CDir 文件管理器

文件视图
在主文件面板内按住 Ctrl 滚动滚轮，可切换视图及图标大小：向上放大，向下缩小至内容视图。中间图标尺寸按文件夹保存，递归应用视图时一并应用；搜索结果同步使用该视图。普通滚动及终端字号缩放保持原有操作。
右上角视图菜单另有分隔的“将当前视图应用到所有子文件夹”和“重置文件夹视图”。应用会覆盖任意深度的已有子目录设置，也适用于尚未访问或以后新建的子目录；重置会将当前目录及全部子目录恢复为详细信息。之后仍可单独修改某个子目录。
中等及更大的主面板项目通过 Windows 缩略图处理器显示图片、视频预览；不支持的格式回退到系统图标，并遵守 Windows“始终显示图标，从不显示缩略图”设置。
大图标使用高分辨率系统图标，避免把小图标直接放大。图片和视频优先显示已有预览；未缓存的预览在后台加载，等待期间先显示清晰的文件类型图标。离开或滚出可视区域的待处理预览会取消，减少无效等待。
点击搜索框右侧下拉菜单，在“显示隐藏项目”上方选择超大图标、大图标、中等图标、小图标、列表、详细信息、平铺或内容。每个文件夹独立保存视图，返回目录时恢复，同一文件夹在不同标签页使用相同视图；各视图继续支持选择、导航、搜索、重命名和拖放。“列表”先从上到下排列，再开始下一列；“内容”按整行显示元数据。未设置过视图的文件夹默认使用详细信息；重启后仍保留各文件夹设置，并恢复已打开目录的视图与滚动位置。
Alt+E（调整所有列宽）及进入目录自动列宽仅在“详细信息”视图生效，其余视图不修改列宽。My Computer 固定按盘符升序显示，C: 在 D: 等后续盘符前；浅灰色升序箭头不响应排序点击。进入普通目录后恢复可排序表头。目录树硬盘用量条稍加粗，提高可读性。

普通窗口可拖动最外侧四边和四角调整大小。Quick Access 加入“我的电脑”，入口固定依次为 Home、Desktop、Documents、Downloads、Pictures、My Computer、Recycle Bin；“我的电脑”在当前标签显示磁盘列表。“关闭其他标签页”保留全部置顶标签，只关闭其他未置顶标签；批量关闭结束后仅刷新一次标签栏并保存一次最终工作区。鼠标侧键的按下和松开只产生一次导航，连续前进/返回按顺序执行。

标题栏在 CDir 右侧显示当前版本，格式为 v大版本号.中版本号.小版本号，初始为 v0.0.0。
大版本完全由人工控制；中版本在修复实际崩溃、卡死等致命 Bug 时自动加 1，也可在新增大功能时由用户明确要求加 1。小版本由发布流程自动管理：源码或配置变动后，在下一次成功发布时加 1；同一源码重复发布或打包、仅构建、测试及发布失败都不递增。增加中版本不会重置小版本或自动改变大版本。
标题和版本的默认字号与侧栏文字相同；可在“偏好设置 → UI → 面板字体大小”独立调整标题栏字号。

启动
解压整个压缩包后，双击 CDir.exe。
请保留同一目录内的所有文件。无需安装程序或另外安装 .NET。
目标系统为 Windows 10 / Windows 11 64 位，目前仅在 Windows 11 x64 验证；Windows 10 尚需实机验收。

多标签页
File 菜单下方为标签栏。点击右侧“+”或按 Ctrl + T，在当前文件夹新建一个标签页；点击标签切换，点击标签上的“×”或按 Ctrl + W 关闭当前页。默认关闭最后一个标签时隐藏到右下角托盘并保留标签；在 Preferences → General 勾选 Exit CDir On Close 后，关闭最后一个标签才退出 CDir。
每个标签包含独立的地址栏、搜索框、侧栏、文件列表、状态栏和终端，分别保留路径、前进后退历史、搜索、排序、选择及侧栏状态。切换标签不会重新加载页面，关闭标签会释放该页的终端和文件监视资源。
Ctrl + Tab 切换到下一页，Ctrl + Shift + Tab 切换到上一页，到首尾后循环；这些按键可在偏好设置中修改。偏好设置仍由窗口统一管理。

分割窗格
将 Tab 拖到当前目录树或主面板的左、右、上、下边缘，会显示半透明吸附预览；松开后，Tab 移入预览范围的新窗格。预览范围包含完整的 Tab 栏、地址栏、搜索框、目录树、主面板、状态栏和终端。中间区域不触发分割；分割来源窗格本身时，来源至少需要两个 Tab。
已分割窗格可以继续嵌套分割，拖动窗格间分隔条时，两侧完整内容实时随动调整大小与比例；空间不足以容纳两个完整窗格时不提供该方向分割。点击窗格后，Ctrl+T、Ctrl+W、Ctrl+Tab 等标签快捷键与批量关闭命令仅作用于该窗格。将 Tab 拖到另一窗格的 Tab 栏可跨窗格移动；关闭或移走最后一个 Tab 后，空窗格自动合并。整个窗口最后一个 Tab 继续遵循现有关闭设置。重启会恢复窗格布局、分隔比例、每个窗格选中的 Tab 和当前活动窗格。

浏览与跳转
点击左侧目录树与右侧文件列表之间分隔条中间的箭头按钮，可隐藏整个左侧栏；隐藏后按钮保留在窗口左边，再次点击即可恢复原来的宽度。显示或隐藏状态会自动保存，下次启动继续沿用。分隔条其余位置仍可拖动调整左侧栏宽度。
左侧是常用位置和目录树。单击目录树中的文件夹只切换右侧目录，不展开该文件夹；单击立即同步右侧目录，不等待双击判定；双击在首次单击导航的基础上展开或收起文件夹，不重复加载目录。跳转时保留侧栏选中状态和滚动位置。点击目录旁的箭头可独立展开或收起，不切换右侧目录。类别标题与收藏根目录之间不连线，展开后的根文件夹保留从文件夹中心向下延伸的完整缩进线；连接子目录的短线及固定目录栏均使用子树的实际线条位置（含内边距）；展开目录时保留各层纵向缩进线，延伸到该分支最后一个可见目录；收起后同步缩短，滚动时保持连续。
点击“常用位置”或“目录树”标题可分别收起、展开整个分区，下次启动会恢复上次的展开状态。
仅在左侧栏空白处右键，选择“新增类别”，输入名称并确认，新分组会追加在目录树及已有自定义类别下方。右键类别标题可选择“展开所有文件夹”或“收起所有文件夹”，递归操作当前类别内的文件夹分支；收起后类别本身及其根文件夹条目仍保持显示。自定义类别还保留“重命名类别”和“删除类别”。名称、顺序和类别展开状态自动保存，常用位置和目录树不允许删除或重命名。
常用位置和自定义类别中的文件夹也支持点击旁边的箭头逐级展开子目录，点击子目录即可打开；子目录可继续拖到其他自定义类别。批量展开遵循隐藏项目设置，跳过目录链接；“收起所有文件夹”会中止当前的批量展开。
右键自定义类别选择“删除类别”时，会先显示带类别名称的确认框，确认后才删除类别及其中的快捷入口；点击取消或关闭确认框都会保留。磁盘上的原文件夹和其他类别中的入口不受影响。
右键点击目录树中的盘符或文件夹，可选择“展开所有子文件夹”和“收起所有子文件夹”，递归操作所点击的分支，不改变右侧当前位置。展开遵循隐藏项目设置，跳过目录链接；收起会停止正在进行的批量展开。
右键目录菜单在“收起所有子文件夹”下方增加分割线和“新建文件夹”。点击后立即在右键点中的目录下创建子文件夹，并在项目位置编辑名称，Enter 确认、Esc 保留默认名称；My Computer、类别中的文件夹入口及展开后的子目录均支持。创建后自动展开父目录显示新文件夹，主面板保持原浏览位置；主面板已在该目录时会选中新建项目。默认名称避开已有文件和文件夹；手动输入重名时提示错误并保留原项目，取消命名则保留已创建文件夹的默认名称。
可从 Windows 文件资源管理器、桌面、其他 CDir 窗口或标签页，以及右侧文件列表拖动文件夹到左侧已有自定义类别的标题或类别内空白处。尚无类别时，请先在左侧栏空白处右键新增。支持同时添加多个文件夹，同一类别内不会重复添加；混合选择中的文件会跳过。类别中显示的是原文件夹的快捷入口，点击即可打开，不会移动磁盘上的文件夹。将文件或文件夹拖到侧栏的具体文件夹时，勾选“拖动时复制文件/文件夹”则复制，未勾选则移动。地址栏、My Computer 和 Quick Access 中拖出的文件夹也支持这两种目标。
按住同一类别内的文件夹条目上下拖动，看到蓝色插入提示线后松开即可排序，拖到侧栏上下边缘可以滚动。文件夹内容和顺序自动保存，下次启动会恢复。右键条目选择“从类别中移除”仅移除快捷入口，不删除原文件夹。
将类别内的文件夹拖到左侧栏以外并松开鼠标，也会从原类别中移除该快捷入口；主面板、顶部工具栏和窗口外均适用。同一文件夹在其他类别中的入口和磁盘上的文件夹不受影响。仅经过侧栏外不会移除；按 Esc 取消或在侧栏内松开会保留入口。
也可以从右侧主面板直接拖动文件夹到左侧自定义类别的标题或类别内空白处，目标类别高亮后松开即可添加；支持同时拖入多个选中的文件夹。新条目追加到类别末尾，已有条目不会重复添加，折叠的类别会自动展开。此操作仅添加快捷入口，不移动原文件夹。
“My Computer”目录树和“Quick Access”中的文件夹也可拖到自定义类别的标题或内容区添加入口。将类别中的文件夹条目拖到另一个自定义类别时，会从原类别移除入口，并追加到目标类别；目标已存在同一目录时保留已有的一份，同时移除来源入口。磁盘上的文件夹不变；同类别内拖动仍用于排序。目录树中拖动文件夹时不会先打开它，单击和双击的导航行为也适用于类别内展开后的子目录树。
按住类别标题拖动，看到蓝色插入提示线后松开即可调整顺序；常用位置、目录树和自定义类别均支持排序。顺序会自动保存，新类别始终追加到最下方。按 Esc 可取消拖动。
主面板以平铺列表显示当前目录中的文件和文件夹。单击文件夹仅选中，双击、按 Enter 或右键选择“打开”可进入该目录；双击文件使用默认程序打开。
文件列表从一开始就将足够的底部空白计入正常滚动范围，使最后一项能滚动到可视区域顶部。即使项目较少、原本无需滚动，也会显示滚动条；滚动过程中滑块长度保持不变，滚轮和拖动滑块使用同一范围。空白不包含可选项目，仍保留行虚拟化。
顶部地址栏按级显示路径，鼠标悬停在文件夹名上会高亮，点击可直接跳转到该级目录。
将地址栏左侧的文件夹图标拖到自定义类别，可以添加当前目录；也可拖动路径中的文件夹名，添加对应的上级目录。拖放后当前地址、主面板目录和浏览历史保持不变，同类别内不会重复添加，也不会移动磁盘上的文件夹。普通单击导航和双击编辑路径的行为保持不变。
从右侧面板、地址栏或前进后退进入文件夹时，左侧目录树会自动展开对应路径及当前文件夹、选中当前目录并滚动到可见位置；收起的“My Computer”分区也会自动打开。目录左侧的 > 箭头只展开或收起，不改变主面板。单击或双击目录名称都会同步更新主面板：单击立即开始跳转，不等待双击判定；双击同时展开或收起目录树，同一目录不会重复加载或增加历史记录。此规则适用于 My Computer、Quick Access、自定义分类的根目录和各级子目录。手动收起优先，后台刷新不会立即重新展开目录；主面板重新获得焦点时，再同步对应目录树。
双击地址栏或其中的文件夹名可编辑完整路径，不会跳转到被双击的目录；单击文件夹名仍可跳转。点击地址栏空白处，或按 Ctrl + L / Alt + D，也可输入、粘贴路径；按 Enter 跳转，按 Esc 取消编辑并返回分段路径。
输入路径后按 Enter 或点击“前往”，会在左侧 My Computer 下展开、选中目标目录并滚动到可见位置，从快速访问或自定义分类开始浏览时也一样。
地址栏编辑时，点击窗口内其他空白区域（包括列表、侧栏、工具栏、状态栏和标题栏），或按 Esc，会取消未提交的输入并移走地址框焦点。框内点击仍可定位光标和选字；“前往”按钮会使用尚未提交的路径进行导航。
路径过长时优先显示当前目录，左侧“…”菜单可选择路径中的任意级目录。
路径可以包含空格、中文或外层引号，也支持 %LocalAppData%、%AppData%、%USERPROFILE% 等环境变量、相对路径和网络共享路径。例如输入 %LocalAppData% 或 %LocalAppData%\Temp，按 Enter 或点击跳转按钮即可进入，地址栏显示展开后的真实目录。
输入文件路径会打开它所在的文件夹并选中文件。
地址栏右侧的复制按钮可以复制当前文件夹的路径。
右上角搜索框按名称递归搜索当前文件夹及其所有子文件夹中的文件和文件夹。
输入关键词即可搜索，例如 report；加 /file 仅显示文件，加 /dir 仅显示文件夹，例如 report /file、/dir work。单独输入 /file 或 /dir 可显示全部文件或文件夹；同时使用两者则显示两类结果。
/file 可简写为 /f，/dir 可简写为 /d，大小写均可。空搜索框获得焦点时显示全部过滤提示；输入 / 后只保留匹配的命令，点击提示可补全当前命令。输入普通文件名、失去焦点或按 Esc 时收起提示。
点击搜索框和提示面板之外的空白区域，会移走搜索框焦点并收起提示，保留已输入的搜索内容。
正则匹配：使用 /regex 或 /r，例如 /regex ^report.*\.txt$ /file。默认不区分大小写，未使用 ^ 或 $ 锚点时可匹配名称中的任意部分。表达式无效或匹配超时时会显示提示。
模糊匹配：直接输入通配符，例如 report*.txt、*report*、资料?.txt；* 匹配任意长度文本，? 匹配一个字符，按整个名称匹配。也可使用 /wildcard 或 /w 显式启用，支持与 /file、/dir 组合。普通关键词仍按名称包含关系匹配。
结果会分批显示，清空搜索后恢复当前文件夹列表。搜索遵循隐藏项目设置，跳过不可访问的子目录，不进入目录链接或 junction。
搜索完成后结果保持稳定，后台文件变化不会自动触发整轮重新搜索；按 F5 可重新搜索并更新结果，修改关键词也会重新搜索。
搜索结果中额外显示“绝对路径”列，可区分不同目录中的同名项目；支持按此列排序，鼠标悬停可查看完整路径。清空搜索后该列隐藏。
“隐藏项目”在“文件 → 偏好设置”中控制；项目数量和操作提示显示在底部状态栏。选中项目时，已选择数量在独立区域显示，不替换原来的总数、文件夹数和文件数；取消选择后自动隐藏。

界面语言
首次使用默认使用英语，已有设置中保存的语言选择会保留。
打开“文件 → 偏好设置”，可在“界面语言”中选择简体中文、日本語、한국어或 English，无需重新启动。
切换后保留当前路径、筛选、排序和选中项目；下次启动会使用上次选择的语言。

表头与偏好设置分类
左右拖动文件列表中任意可见表头，即可调整各列的显示顺序；点击表头仍可按该列排序。
点击表头切换升序和降序：当前排序列表头右侧显示加粗蓝色箭头，↑ 表示升序、↓ 表示降序；其他列隐藏箭头。
偏好设置左侧分为 General（常规）、UI、Terminal Theme（终端主题）和 Keyboard Shortcuts（快捷键）。常规中可设置语言、12/24 小时制、隐藏项目和关闭窗口时的行为；UI 中可设置面板字体大小、网格线和显示的列。
Alt+S 默认打开 Preferences，可在 Keyboard Shortcuts → Preferences 中自定义、清除或恢复默认，File 下拉菜单同步显示当前按键。升级时保留已有的个人 Alt+S 绑定。UI 页在字体设置与下方显示选项之间使用“目录树，标签栏和主面板显示”小标题。
UI 页的修改会在偏好设置窗口仍打开时立即应用到当前主窗口的全部标签页，包括未选中的标签页和其他窗格；新标签继承这些设置，恢复 UI 默认设置时也同步更新全部标签页。
在 UI 中勾选或取消名称、修改日期、类型、大小、绝对路径，立即控制这些列的显示状态。普通浏览至少保留一列；绝对路径列仅在搜索结果中显示。
列顺序和显示状态自动保存，关闭、重新启动后恢复；调整列不会重新运行搜索。

系统图标
文件列表、目录树、常用位置和地址栏使用 Windows Shell 提供的系统图标。
文件的默认关联程序图标、应用程序和快捷方式图标，以及自定义文件夹图标均跟随 Windows 设置。
保留快捷方式箭头；Git/SVN 状态由程序直接查询工作区后单独显示，不沿用第三方 Shell 扩展的缓存标记。
位置不可访问、系统扩展未返回图标或读取超时时，会显示系统通用图标。
更改文件关联或文件夹图标后，可按 F5 同时刷新目录和图标。
图标只缓存在内存中，不会另存图标文件到磁盘。
列表保持 16 DIP 图标，默认内容行高为 22 DIP，网格线默认关闭，开启网格线不改变行布局，字号增大时行高自动增加；标题栏保留 CDir 品牌图标，命令按钮保持简洁字形。

Git / SVN 状态
自动识别当前目录所属的 Git / SVN 工作区，普通目录不显示额外状态图标；嵌套仓库使用最近一层工作区。
需要本机安装 Git 2.31+ 或 SVN 1.8+ 命令行；支持从 PATH、安装注册表或标准目录找到 git.exe / svn.exe，包括其他磁盘安装的 TortoiseSVN。
绿色勾表示已跟踪且未修改；红色叹号表示修改，红色叉号表示冲突；加号、减号、斜箭头分别表示新增、删除、重命名。
蓝色问号表示未跟踪，灰色减号表示忽略；图标右下角三个点（...）表示正在核实，完成后自动替换成对应状态徽标；灰色问号表示状态不可用，悬停可查看原因。
文件显示自身状态；仓库内目录汇总子项变化，悬停会说明目录内包含的变化。未修改的兄弟文件不会被标红。
忽略项不使父目录变脏；Git 未跟踪的空目录不显示徽标；仓库以外的祖先目录不跨仓库汇总。
优先查询主面板当前目录，各仓库独立发布状态；SVN 合并可见目录查询并复用根验证，先显示文件状态，再优先递归核实当前子树，其他未核实范围继续显示待确认；Git 汇总未跟踪目录，避免逐个输出其后代文件。
SVN 状态同时考虑内容和属性：按可见目录读取未修改文件清单，同时用非 verbose 的递归查询汇总本地变化，让未展开的深层修改也能反映到父文件夹图标。
SVN 目录汇总包括未展开深层子树中的本地变化。尚未核实的 external 不会被标为干净。
首次进入仓库时查询一次，此后仅在文件或有效版本元数据发生变化时自动刷新，不再定时轮询或因切回窗口重查。
同一仓库内切换目录、滚动目录树会复用状态；连续文件变化合并处理，避免反复取消查询。按 F5 可强制刷新；监视不可用时请手动刷新。
提交、还原、深层文件变化后会重新查询，切换目录时不会沿用旧查询结果。
查询失败或超时会显示状态不可用，不猜测是否修改；结果表示最近一次成功查询时的本地状态。
程序只读取状态，不执行提交、更新或还原，也不查询远端服务器。

快捷键
在“文件 → 偏好设置 → 快捷键”中修改可自定义的应用快捷键（包含编辑路径的两组按键）。列表仅显示可自定义的项目，并始终按功能英文名称升序排列。新窗口 Ctrl + N、主面板复制 Ctrl + C、剪切 Ctrl + X、粘贴 Ctrl + V 和终端 Ctrl + 滚轮为固定快捷键，不列入自定义列表；输入框中的复制和粘贴仍按文本编辑方式处理。
支持按功能名称或按键组合实时搜索；点击输入框并按下新组合键即可设置，立即生效并保存。
可自定义的项目均可清除或重置；重复绑定会提示冲突，不会覆盖其他功能。Ctrl + N 固定为新建独立的 CDir 进程，复制当前窗口的完整工作区，包括标签页、列宽、选中项目和目录树展开状态，不可修改或清除；从程序图标启动新实例时复制最近活动的 CDir 窗口。文本编辑及对话框中的 Enter、Esc、Tab 保留原有行为。
按钮提示和帮助中的应用快捷键会同步更新。Windows Shell 原生右键菜单由系统管理，不随应用快捷键设置改变。以下为默认按键：
Ctrl + T：新建标签页
Ctrl + N：新建 CDir 窗口（固定快捷键）
Ctrl + W：关闭当前标签页
Ctrl + Tab / Ctrl + Shift + Tab：下一个 / 上一个标签页
Ctrl + L / Alt + D     编辑地址栏
Ctrl + Shift + C       复制当前文件夹路径
Alt + 左 / 右 / 上      后退 / 前进 / 上一级
Alt + X                显示或隐藏内嵌终端
Ctrl + F               搜索当前文件夹及子文件夹
F5                     刷新目录与图标
Ctrl + Shift + N       新建文件夹
Ctrl + C / X / V       复制 / 剪切 / 粘贴
左侧目录树选中目录后按 Ctrl + C，可复制该目录的绝对路径；此处为固定的目录树按键。
在右侧按住目录准备拖到分类时，左侧目录树会保持原状，松开鼠标或结束拖拽后再同步。
Ctrl + A               在文件列表中全选
Enter                  打开所选项目
F2                     重命名
Delete                 移到回收站

内嵌终端
点击右下角状态栏的 Terminal（终端）按钮，或按 Alt + X，在文件列表下方显示或隐藏 PowerShell 终端。
首次打开时使用当前显示的目录；隐藏后保留会话、工作目录、环境和输出，文件列表切换目录不会自动改变已有终端的位置。
拖动终端上方的分隔条可调整高度。标题栏的箭头隐藏终端，重启按钮会结束原会话，并在文件列表当前目录启动新会话。
终端中的复制、粘贴等按键交给终端处理，不会操作文件列表。默认切换快捷键也可在偏好设置的快捷键分类中修改。
终端中按 ↑ 显示上一条命令，按 ↓ 显示下一条命令；回到最新位置时恢复尚未提交的输入。历史保留在当前会话中，隐藏终端不会清除，重启终端后清空。
“偏好设置 → 终端主题（Terminal Theme）”位于 UI 下方，可以调整终端字体大小（8–48）和背景颜色。选择色块或输入 #RRGGBB 自定义颜色，预览和已打开的终端立即更新并自动保存，不会重启会话。浅色背景自动使用深色文字。
鼠标悬停在终端范围内即可用 Ctrl + 滚轮上划/下滑调整字体，无需先聚焦；聚焦后也可用 Ctrl + +、Ctrl + - 和数字键盘加减键。底栏 Background Color 右侧显示操作提示。
调整字号时光标与输入法位置同步更新。终端点击后的输入焦点交给原生文本输入控件，中文等输入使用系统输入法，在候选中确认后才发送到终端；组词期间的 Enter、退格和方向键交给输入法处理，取消组词不会执行命令。中文、日文、韩文等字符使用对应的系统字体回退显示。
自动补全建议及其帮助提示采用柔和灰色（#6F6F6F），已输入命令仍按原有语法配色显示。
终端字号的键盘增减绑定仍可自定义；Ctrl + 滚轮缩放为固定操作，不允许修改或清除。
终端聚焦时按 Ctrl + 0（也支持数字键盘 0）恢复默认字号 15，此操作也可在快捷键面板修改。终端底部信息栏从左到右显示当前字号、背景颜色及其 #RRGGBB 代码，并随设置和快捷键操作实时更新。
“终端主题”中的背景颜色下方可调整字体颜色，支持色块和自定义 #RRGGBB。默认启用自动字体颜色，取消勾选后可自定义；选择字体色块会自动切换为自定义颜色。字体颜色立即应用并自动保存，恢复默认设置后重新启用自动配色。
Ctrl + V、Ctrl + Shift + V、Shift + Insert 和右键菜单的粘贴均将文本直接发送到终端，避免写入不可见的输入框；支持中文及多行文本。

操作说明
新建文件夹、F2 和单项右键重命名均在项目位置编辑名称；Enter 确认，Esc 取消命名并保留原名，新建文件夹保留默认名称。文件默认只选中文件名主体、不含扩展名。编辑框内的复制、粘贴、全选及撤销保留文本编辑行为。
复制和移动全程使用 Windows 原生文件操作，包括统计文件数量与大小、冲突询问、进度及取消。进度窗口的出现时机由 Windows 决定。取消后保留已经完成的项目，并刷新当前及其他已打开标签页。
双击文件会调用 Windows 的默认程序。新建文件夹、剪切、复制、粘贴、重命名和删除可通过右键菜单或快捷键操作。
文件列表的文件、文件夹和空白处使用 Windows Shell 原生完整右键菜单，对应 Windows 11 的“显示更多选项”。菜单命令、图标、文件关联和第三方扩展由 Windows 提供，由 CDir 补齐查看、排序、分组、刷新、自定义文件夹和终端等背景操作。空白处固定请求当前文件夹的背景菜单，即使打开菜单期间旧文件选择被恢复，也不切换成文件菜单。按住 Shift 右键可显示系统扩展命令；多选按系统规则提供共有命令。重命名由 Windows Shell 执行，支持批量编号。
在主面板空白处右键，选择“新建”可在当前目录创建文件夹或系统已注册的文件类型。
在同一文件夹内复制粘贴时，副本命名及重名编号由 Windows 决定，保留原文件及扩展名。替换、跳过、取消和文件夹合并均由 Windows 原生文件操作处理。
批量操作可能部分完成；失败或取消后，已经完成的项目会保留。
应用按钮及快捷键的删除会交给 Windows 回收站并保留系统确认，网络盘和可移动磁盘的回收操作会被拒绝；原生右键菜单的删除按系统策略处理，普通删除优先进入回收站，按住 Shift 删除仍为永久删除。删除任务在独立后台线程执行，系统确认和进度窗口不锁定主窗口，可继续浏览、搜索、新建和切换标签页；正在执行文件操作的标签页会保留到任务结束后再允许关闭。
如果 Windows 提示无法回收，请检查系统对话框后决定是否继续。
Windows 10、跨卷移动、网络共享及回收站交互尚未完成实机验证。

设置
最后访问的位置、窗口大小、隐藏项目开关、界面语言和左侧分区展开状态会保存到：
%LOCALAPPDATA%\CDir\Settings.json
首次启动 CDir 时会自动迁移旧 DocReader 设置，保留语言、自定义类别和侧栏顺序；若已有 CDir 设置，则优先使用现有设置，旧配置文件保留。
在“偏好设置”窗口底部点击“恢复默认设置”，先弹出范围选择：默认选中当前分类，也可选择全部偏好设置。取消或按 Escape 不作更改。General 恢复语言、时间格式、隐藏项目、关闭行为、拖放时复制、文件夹大小计算和开机启动；UI 恢复九个面板字号、网格线、显示选项以及列顺序与可见性；Terminal Theme 恢复终端字号及颜色；Keyboard Shortcuts 恢复自定义快捷键。单独恢复分类时保留其他分类的设置。更改即时生效并自动保存，保留当前位置、窗口大小和自定义分类。文件列表网格线默认关闭。终端默认字号为 15，背景为 #1E1E1E，标题栏背景同步跟随终端背景颜色。
源码中的默认配置统一保存在 Source\Config\DefaultSettings.json，构建时嵌入程序，首次启动及恢复默认偏好设置均使用这份配置。

程序没有账号、遥测或自动更新检查。

面板字体大小：在“偏好设置 → UI”中，可分别调整文件列表、列表表头、侧边栏、地址与搜索栏、菜单、状态栏、标题栏和偏好设置的字号（8–24），即时生效并自动保存。
浅色界面采用三层中性灰白：最外层窗口和标题区为 #F3F3F3，中层侧栏和工具区为 #FBFBFB，内层列表与输入区为 #FFFFFF；聚焦提示为 #F3F3F3。菜单和偏好设置同步使用此配色，终端仍使用其独立主题设置。

关闭与通知区域
CDir 启动后即在右下角通知区域显示图标；窗口显示、最小化或隐藏时，图标始终保留，退出进程时才移除。默认点击窗口右上角的关闭按钮时，CDir 会隐藏，进程及标签页继续保留。双击 CDir 图标即可恢复窗口；图标也可能位于 Windows 通知区域的折叠菜单内。
右键通知区域中的 CDir 图标，可选择打开或退出。正在执行文件操作时，退出仍会受到原有保护。
在 Preferences → General（偏好设置 → 常规）中勾选“关闭窗口时退出 CDir”，关闭按钮就会直接退出进程。取消勾选可恢复隐藏行为；该设置立即保存，重启后保留。

滚动条与横向滚动
横向和纵向滚动条统一缩窄为 12 个逻辑像素。左侧目录树的横向、纵向滚动条平时隐藏，滚动时立即显示，持续滚动会保持可见；停止约一秒后隐藏，悬停或拖动期间保持显示。也可在滚动条区域持续悬停约 150 毫秒使其显示；快速从主面板移到侧边栏或反向移动时不会闪现，直接按住或拖动时立即显示。主面板的滚动条在有可滚动内容时持续显示。所有滑块保持浅灰色直角矩形，悬停时略微加深，按住拖动时显示蓝色。
Shift + 滚轮固定用于鼠标所在区域的横向滚动：向下滚轮向右滚动，向上滚轮向左滚动。此操作不能自定义，普通滚轮仍用于纵向滚动。
快捷访问、我的电脑和每个自定义类别均支持独立横向滚动。通过 Shift + 滚轮、横向滚轮或拖动横向滚动条可查看完整名称、路径和容量信息；每个类别的根文件夹与展开后代一起移动，类别标题保持固定，普通滚轮继续纵向滚动。

顶部菜单
File（文件）菜单中，Preferences（偏好设置）下方以分割线隔开 Exit（退出）。选择 Exit 可直接退出 CDir；正在进行文件操作时会保留退出保护。File 右侧的 Help（帮助）目前仅作为菜单标签保留，尚无功能。

主面板框选
在列表空白处或名称文字右侧的空白处按住鼠标左键拖动，可框选多个文件和文件夹。拖动至列表上、下边缘可自动滚动继续选择。Ctrl + 框选可增减选中项，Shift + 框选可追加选择，Esc 取消当前框选并恢复框选前的选择。松开鼠标后保留选中结果。
在文件夹图标或名称文字上拖动，仍使用原有的拖到侧栏类别功能。

拖放复制与移动
支持从 Windows 文件资源管理器、其他文件管理器、桌面或另一个 CDir 窗口拖入文件和文件夹，兼容标准文件列表及可转换的 Windows 文件名格式，也可拖动当前主面板中选中的多个项目。放到主面板空白处时传入当前目录；放到文件夹行或侧栏的实际文件夹上时传入该文件夹。拖动时显示目标及复制/移动提示。
Preferences → General（偏好设置 → 常规）中的“拖放时复制文件和文件夹”默认勾选，拖放时复制并保留原文件；取消勾选后执行移动。已保存的个人选择会保留；恢复默认设置会开启此选项。设置立即保存，并同步至其他标签页。已有同名项目时由 Windows 询问替换、跳过或取消；拖回原目录时不执行复制或移动，也不生成副本；文件夹自身及子目录目标不接受。
从外部位置或当前窗口拖放文件夹到自定义类别时，均添加快捷入口。
主面板文件夹拖到自定义类别标题或类别内空白处时添加快捷入口；拖到具体文件夹时，按拖放复制设置执行移动或复制，且不会加入类别。
主面板按 Ctrl+X 后，待剪切文件和文件夹淡化显示；按 Esc 取消剪切并恢复显示，之后粘贴不会执行已取消的移动。刷新或切换标签页保留待剪切状态；复制新内容或成功完成剪切粘贴后自动恢复显示。
右键文件或文件夹选择“剪切”也会淡化目标，Esc 取消和粘贴完成后的状态处理与 Ctrl+X 一致。
Alt+Q 显示或隐藏整个左侧目录栏，可在“偏好设置 → Keyboard Shortcuts → 显示或隐藏目录树”中修改、清除或恢复默认。Ctrl+F 聚焦右上搜索框后，Esc 将焦点移回文件列表、关闭搜索提示并保留查询。Quick Access 的“回收站”使用与普通目录相同的主面板表格，图标读取系统回收站默认图标；支持前进、后退、刷新和独立标签页，项目还原和删除等命令由 Windows 提供。
文件和文件夹也可拖到地址栏中的某一级目录名称上；目标高亮后松开，未勾选拖放复制时移动到该目录，勾选时复制到该目录，当前浏览位置保持不变。地址栏空白区域不接收文件拖放。
最大化窗口按当前显示器的工作区设置边界，底部状态栏保留在任务栏上方。应用快捷键由主窗口统一转发，Alt + X 可从文件列表、输入框或终端中显示/隐藏终端。

导航按钮仅在鼠标悬停或按下时显示高亮；点击后移开鼠标即恢复普通样式。键盘导航时保留焦点边框。

文件操作记录、撤销与重做
在同一个文件夹内复制生成副本后，Ctrl+Z 可撤销该次复制，Ctrl+Y 可重做；保留原文件和 Windows 自动生成的副本名称。
File 菜单提供撤销（Ctrl+Z）和重做（Ctrl+Y），两组快捷键固定且不能自定义。支持的新建文件夹、重命名、复制、移动和移入回收站操作使用 Windows 共享的文件操作历史，可用性及冲突处理由 Windows 决定。永久删除不可撤销。文本输入框保留文字编辑的撤销与重做。
Esc 关闭当前编辑、提示、菜单或对话框后，将焦点返回主面板文件窗口；终端中按 Esc 也返回文件面板。原有取消剪切、取消框选和清除文件选择行为保留。
操作元数据记录位于 %LOCALAPPDATA%\CDir\OperationHistory。CDir 不再在原生操作前扫描和备份文件内容。撤销历史、回收站、还原、永久删除及清空回收站均由 Windows 管理。
地址栏目录段单击后的等待最多为 180 毫秒，快速双击仍可进入完整路径编辑。

Ctrl+A 固定全选当前主面板显示的文件和文件夹，不能在偏好设置中修改或清除。压缩包统一为 Publish/CDir_WinX64_v大版本.中版本.小版本.zip，Artifacts 保留相同副本；解压后得到同名版本文件夹。
回收站中 Ctrl+F 可聚焦搜索框并按原始显示名称筛选；Ctrl+A 全选当前显示的项目，清空搜索恢复全部项目。

回收站与普通目录共用文件面板，增加“原位置”和“删除日期”两列，两列固定显示且不能隐藏。搜索框右侧的下拉菜单列出表头，已显示的列在最右侧标记 √，点击后切换显隐；回收站的两列固定项保持勾选、不可切换。

v1.0.0 交互更新
Size 列逐步显示文件夹内所有普通文件的递归合计大小，包含隐藏文件；后台串行、分批统计，切换目录或标签、隐藏 Size 列时停止未完成任务。— 表示未知，≥ 表示部分统计；不递归进入符号链接或联接目标，子目录内容变化后按 F5 重新计算。终端连续删除时不再逐帧复制全部历史文本，减少输入法宿主布局更新，并合并积压的输入写入，单次输入仍立即发送。
行内文件名编辑时保留文本全选；主窗口其他场景无论焦点位于搜索框、地址栏、侧栏、标签栏还是终端，Ctrl+A 都切回主面板，全选当前显示的结果并保留筛选。Preferences、重命名等弹窗保持打开，保留普通文本全选。鼠标侧键和驱动发送的浏览器命令在当前标签页内后退、前进。File、Help 与托盘菜单具有随字号调整的最小宽度；File 在 Exit 上方增加 About，About 下方保留分割线，托盘仍只有 Open、原有分割线和 Exit。Preferences 为四种语言预留统一分类宽度，切换语言时侧栏和内容位置保持稳定。新用户默认偏好设置保存在 Source/Config/DefaultSettings.json；自定义分类、目录路径和导航状态仅保存在用户 Settings.json 中，不写入内置默认配置。

“偏好设置 → General → 开机自动启动 CDir”默认不勾选；勾选后，当前 Windows 用户登录时自动启动此位置的程序，取消勾选或恢复默认设置会移除此副本的启动项，不需要管理员权限。

异常退出与断电恢复
只有一个实例运行时，当前窗口约每秒自动保存工作区，包括标签、活动目录、标签名称、导航历史、搜索与排序、选择、列宽、侧栏和终端面板布局、窗口位置。配置采用刷盘后的原子写入并保留 .bak 备份。重启后恢复最近一次完整保存的状态；主文件不可读时使用备份。突然断电仍可能丢失最后一次完整写入之后的更改；终端面板会创建新的 Shell 会话。工作区文件位于 Settings.json 同目录，名称为 Settings.json.workspace.json，并保留 .bak 备份。

Windows 关机、重启或注销时，CDir 自动保存每个实例的独立工作区快照，不弹覆盖确认、不因正在操作文件而阻止系统结束会话，也不等待其他实例响应。下次启动优先恢复最近活动窗口的完整配置和标签页。多实例运行期间也定期保存独立快照；普通退出仍沿用配置冲突确认。快照保存在 Settings.json.workspace.json.sessions，较新的正常保存优先于旧快照。

应用菜单的分割线使用统一紧凑模板，占满可用菜单宽度，不保留 Windows 默认的图标栏缩进；菜单文字继续使用用户设置的字号。

多个 CDir 进程同时运行过时，暂停自动写入共享配置与恢复文件。退出时仅当其他进程写入的配置既不同于本实例缓存的基线、又不同于当前窗口的待保存内容时才询问覆盖：选择“是”用当前窗口的布局和配置覆盖，“否”退出而不保存，“取消”保留窗口；其余情况自动保存退出。相同内容、激活时间及 JSON 格式变化不会触发冲突。隐藏到托盘仍保留进程。从主面板拖动文件夹添加到 Category 后，不再展开源目录树。文件数量和大小统计及传输进度由 Windows 显示；完成、取消或失败后先清理 CDir 操作状态，再刷新面板。

支持从 Windows 回收站或 CDir 回收站视图拖出文件和文件夹到普通目录。Windows 自带回收站只允许移出，因此即使勾选“拖动时复制文件/文件夹”，也按原生规则移出到目标目录，并显示移动提示；保存的复制偏好不变。支持复制的来源仍按复制选项执行。保留 Shell 项目标识以使用原名称及系统元数据，由 Windows 处理进度、同名冲突和取消。

Preferences → UI（偏好设置 → UI）中的“显示文件夹路径”默认不勾选。启用后，自定义分类、快速访问和 My Computer 的所有文件夹（包括展开的子目录和置顶父目录）均显示绝对路径，路径列与磁盘容量面板对齐，调整侧栏宽度时保持对齐。磁盘名称旁不再重复显示根路径，展开目录的绝对路径仍保留；空间不足时省略，悬停名称或路径立即显示完整路径。设置保存并同步到其他标签页。只有展开的文件夹分支固定父级行，分类标题在下一分类进入时退让，不依赖主面板所在目录。

显示选项
搜索框右侧下拉菜单末尾新增分隔线及“显示隐藏文件/文件夹”，与 Preferences → General 同步。关闭文件列表网格线也会隐藏条目下方分割线。Preferences → UI 包含“显示文件夹路径”和“显示我的电脑中的磁盘用量”；磁盘用量默认不勾选，同时控制盘符名称右侧同一行的容量、固定 64 逻辑像素宽的用量条及百分比。
Preferences → UI 新增“打开文件夹时自动适配列宽”，默认关闭。开启后每次打开文件夹（包括新建 Tab）时，根据表头和文件夹内容适配所有显示列；后台刷新保留手动调整的宽度。选项会保存，恢复默认设置时关闭。

置顶标签和普通标签可分别拖拽排序。开启置顶标签单独一行且该行已显示时，跨行拖拽可置顶或取消置顶，并按释放位置插入；拖拽时显示插入标记，行边缘自动横向滚动。标签顺序和置顶状态会保存。

将文件或文件夹拖回原目录时不执行任何复制或移动，不生成副本；另一个窗格显示同一目录时也适用。跨目录拖放仍按复制/移动偏好执行。

右键文件列表任一表头，选择“调整所有列宽至合适大小”，或在当前 Tab 有焦点时按 Alt+E，可一次调整当前 Tab 所有显示列。每列取表头和当前列表内容的最大宽度，包含尚未滚动到的文件/文件夹；筛选状态下以当前结果为准。其他 Tab 不受影响。快捷键可在偏好设置 → Keyboard Shortcuts 修改、清除或恢复默认。侧栏切换默认改为 Alt+Q；升级时一次性迁移原默认 Alt+1，保留其他个人绑定及已占用 Alt+Q 的个人设置。

Alt+R 可尽可能均匀分布当前主窗口内所有分割窗格，先按列均分整个窗口的宽度，再按每列的行数均分该列高度；兼容更多列、更多行和连续嵌套分割，某列内的行数不会挤占其他列的宽度。遵守完整窗格的最小尺寸。保留分割方向、Tab 内容及当前活动窗格，调整后的比例自动保存。在偏好设置 → Keyboard Shortcuts 的“均匀分布所有窗格”中可自定义、清除或恢复快捷键。

启动恢复工作区
优先显示上次活动的文件夹，再优先恢复其他窗格的选中标签。其余标签恢复时不再反复切换当前标签；文件夹读取、搜索和终端恢复采用受限并发，创建界面控件之间让出时间处理输入与绘制。复用首次读取的磁盘列表，各标签独立恢复目录树状态，保留标签顺序、置顶、选择和窗格布局。
文件列表读取完成后即可操作，磁盘信息和保存的侧栏分支随后补齐。自动列宽测量和大目录树更新分小批处理输入；加载期间的新导航和文件选择优先于迟到的工作区恢复，不保存尚未恢复完整的工作区。

在“偏好设置 → UI”的面板字体大小下方新增“所有字体加粗”，默认关闭。勾选后全部界面和终端字体立即加粗，自动保存并同步至所有标签页和窗格；取消勾选恢复原有字重，恢复 UI 默认设置时关闭此选项。

终端选中文字后，按 Ctrl、Shift、Alt 或 Windows 键会保留选区；有选区时 Ctrl+C 和 Ctrl+Shift+C 复制终端选中文字，无选区时 Ctrl+C 仍用于中断当前终端命令。
